# goit-js-hw-02

Початкова структура домашнього завдання №2 з JavaScript.
Файли `task-1.js`–`task-4.js` підготовлені для розв'язання завдань.

## Структура проєкту

```text
goit-js-hw-02/
├── js/
│   ├── task-1.js
│   ├── task-2.js
│   ├── task-3.js
│   └── task-4.js
├── .gitignore
├── .prettierrc
├── index.html
└── README.md
```

## Запуск

Відкрийте папку проєкту в редакторі та запустіть `index.html` через локальний
HTTP-сервер, наприклад Live Server. Для перевірки результатів відкрийте
інструменти розробника браузера → Console.

Усі чотири JavaScript-файли підключені до `index.html` як окремі модулі.
Зовнішні бібліотеки не потрібні.
