# goit-js-hw-02

Домашнє завдання №2 з JavaScript.

## Завдання

| Файл           | Функція                                                     | Призначення                                                       |
| -------------- | ----------------------------------------------------------- | ----------------------------------------------------------------- |
| `js/task-1.js` | `makeTransaction(quantity, pricePerDroid, customerCredits)` | Перевіряє баланс клієнта та повертає повідомлення про замовлення. |
| `js/task-2.js` | `formatMessage(message, maxLength)`                         | Обрізає задовге повідомлення та додає `...`.                      |
| `js/task-3.js` | `checkForSpam(message)`                                     | Шукає `spam` або `sale` без урахування регістру.                  |
| `js/task-4.js` | `getShippingCost(country)`                                  | Визначає вартість доставки за допомогою `switch`.                 |

Усі 24 перевірочні виклики з умов залишено у відповідних файлах для ментора.
Код відформатовано Prettier відповідно до `.prettierrc`.

## Структура проєкту

```text
goit-js-hw-02/

│   ├── task-3.js

└── README.md
```

## Запуск

Відкрийте [живу сторінку](https://rossors.github.io/goit-js-hw-02/) або
запустіть `index.html` через локальний
HTTP-сервер, наприклад Live Server. Для перевірки результатів відкрийте
інструменти розробника браузера → Console.

Усі чотири JavaScript-файли підключені до `index.html` як окремі модулі.
Зовнішні бібліотеки не потрібні.
